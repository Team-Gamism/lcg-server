# 내전 모집·팀 구성·결과

## 요구사항 해석

일반 파티와 유사하지만 정원 10명, 포지션별 2명, 팀별 5명·포지션별 1명이라는 별도 규칙이 있어 Inhouses 모듈로 분리한다. 공통 모집 로직은 필요한 부분만 재사용한다. 시간·참가·팀 편성·결과는 서버의 확정 상태로 관리한다.

```text
Recruiting → Ready → TeamsAssigned → InProgress → Completed
Recruiting/Ready/TeamsAssigned → Cancelled
```

시작 전 이탈 시 팀 확정을 취소하고 모집 상태로 돌아가는 기본안을 제안한다. 경기 시작 뒤 명단 변경은 일반 수정에서 금지하고 별도 중단·운영자 정정 절차로 처리한다.

## LCG API 초안

`GET/POST /api/v1/inhouses`, `GET/PATCH /api/v1/inhouses/{inhouseId}`, 하위 `/applications`, `/members`, `/positions`, `/teams`, `/teams/randomize`, `/start`, `/cancel`, `/result`, `/result/confirm`, `/result/dispute`, `/result/consents/me`를 제안한다. 신청·회원 하위 리소스의 메서드·권한은 Parties와 일관되게 정한다. 팀·결과 변경은 버전 충돌을 검출한다.

## 확인할 외부 제약

Riot은 LoL 커스텀 경기 기록의 공개에 별도 동의를 요구한다. 데이터가 기술적으로 조회된다는 것만으로 공개가 허용되는 것은 아니다. 수집과 노출을 별도로 판단하고 MVP 내전은 수동 결과로 진행한다. [Riot LoL Game Policy](https://developer.riotgames.com/docs/lol#game-policy)
