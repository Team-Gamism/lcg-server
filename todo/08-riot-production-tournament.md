# Riot 정식 연동·대회 확장

## 선행 조건

기획서의 Phase 4는 정식 Riot 연동 기능의 고도화 단계로 유지하되, 제품 등록·키 사용 자격·승인 준비는 `RIOT-01`, 공개 출시 확인은 `OPS-02`에서 먼저 한다. **P4는 중요도가 낮다는 뜻이 아니라 외부 승인과 앞선 도메인 완성에 의존한다는 뜻**이다.

RSO 접근에는 Production 수준 API 키와 Riot의 연동 절차가 필요하다. Production 키만 발급받으면 모든 RSO 설정이 자동으로 끝나는 것으로 가정하지 않는다. [RSO Integration](https://developer.riotgames.com/docs/lol#rso-integration)

## 이후 결정할 범위

참가비·상금·스폰서·결제·방송 기능은 현재 기획의 서버 MVP 범위가 아니다. 필요해지면 별도 요구사항을 작성한다. 대회 자동화는 수동 운영 경로가 안정화된 후 추가한다.

외부 연동 재확인 자료: [Riot Developer Portal](https://developer.riotgames.com/docs/portal), [Tournament API](https://developer.riotgames.com/docs/lol#tournament-api), [Riot 일반 정책](https://developer.riotgames.com/policies/general).
