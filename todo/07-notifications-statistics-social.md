## 통계 집계 계약 제안

통계는 **학교 전체 경기 전수**가 아니라 **동의한 대상자의 수집된 경기 표본**임을 응답에 명시한다. 계정 자격/소유 확인 조건은 `RANK-01`과 일치시키고, 누가 학교 통계에 들어오는지와 수집 지연을 기록한다.

| 지표 | 제안 정의 |
| --- | --- |
| 사용자 챔피언 플레이 수 | 필터 범위에서 중복 제거한 `(matchId, puuid)` 중 해당 챔피언으로 플레이한 수 |
| 챔피언 승률 | 같은 모집단에서 해당 챔피언 승리 참가 건수 / 유효 참가 건수 |
| 챔피언 픽률 | 같은 모집단에서 해당 챔피언 참가 건수 / 전체 학교 대상자 참가 건수; 전체 LoL 픽률과 구분 |
| 주간 학교 게임 수 | 해당 주에 시작한 대상 경기의 `distinct matchId`; 5명 동반 참가도 1경기 |
| 주간 학교 플레이 건수 | `(matchId, puuid)` 건수; 게임 수와 별도 지표 |
| 주간 생성 파티 | 주간 생성된 Party ID 수; 포함할 취소 상태 규칙을 고정 |
| 주간 진행 내전 | 완료 시각이 주간에 속한 Completed 내전 ID 수; 모집글 수와 구분 |

기본 주간 경계는 서울 월요일 00:00 이상 ~ 다음 월요일 00:00 미만이다. 큐·패치·기간, 다시하기/중단 경기 포함 여부를 필터 계약으로 고정한다. 승률 순위는 초기 최소 30개의 유효 참가 건수를 제안하며, 화면의 '게임 수' 의미와 API 단위를 일치시킨다. 분모가 0이면 비율은 null로 반환한다.
