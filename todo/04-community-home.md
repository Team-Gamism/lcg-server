# 커뮤니티·클립·홈

## 요구사항 해석

`전체`는 조회 필터이며 저장 카테고리는 자유/질문/공략/클립/내전으로 구분한다. 대댓글은 초기 1단계로 제한하는 안을 제안한다. 작성자 닉네임·공개 티어·포지션은 공통 프로필 DTO를 사용한다. Riot 계정 미등록 회원도 커뮤니티를 사용할 수 있다.

## LCG API 초안

`GET/POST /api/v1/posts`, `GET/PATCH/DELETE /api/v1/posts/{postId}`, `GET/POST /api/v1/posts/{postId}/comments`, `PATCH/DELETE /api/v1/comments/{commentId}`, `PUT/DELETE /api/v1/posts/{postId}/reaction`, `POST /api/v1/reports`, `GET/PATCH /api/v1/admin/reports/{reportId}`, `GET /api/v1/home`.

신고 목록은 `GET /api/v1/admin/reports`로 별도 제공한다. 인기글과 클립은 posts의 필터/유형으로 시작하고 독립된 댓글·추천 테이블을 중복 생성하지 않는다.
